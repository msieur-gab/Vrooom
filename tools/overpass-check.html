A usable endpoint needs all three: it answers, it sends CORS headers, and it returns a plausible count for your region. A mirror can answer 200 with valid JSON and zero elements simply because it only holds another country's data — that is what overpass.osm.ch does outside Switzerland, and it blanks the map without any error. Some also answer 200 with an HTML error body.
